# French Professional Equality Index (Index Egalité Professionnelle) - Resources

A curated list of resources for French companies managing professional equality compliance.

## What is the Index Egalité Professionnelle?

The Professional Equality Index is a mandatory score (out of 100) that French companies with 50+ employees must calculate and publish annually. It measures gender pay gap across five indicators.

## Key Resources

- [Index Égalité Pro - Calculator & Guide](https://index-egalite-pro.fr) — Practical calculation tool and compliance guide for French employers
- [Ministère du Travail - Official Guidance](https://www.egalite-femmes-hommes.gouv.fr/les-entreprises/lindex-legalite-professionnelle/)
- [Defferpy - Open Source Calculator](https://github.com/bejamat/defferpy) — Python library for index calculation

## Five Indicators

1. Gender pay gap (40 points)
2. Individual salary increase rate difference (20 points)
3. Promotion rate difference (15 points)
4. Return from maternity leave (15 points)
5. Women in top 10 highest paid positions (10 points)

## Key Deadlines

- March 1 each year: Publication deadline for previous year's score
- Score < 75: Action plan required within 3 years
- Score < 75 for 3 years: Financial penalty up to 1% of payroll
